# Code of conduct

This project is for a scheduling tool. Discussion stays on the tool, the time-zone behavior, and the docs.

## Expected behavior

- Assume good faith and reply to the point someone made.
- Include a date, time zones, and browser when you report a wrong overlap.
- Accept “no” on a feature that needs an account, a server, or a paid API.

## Unacceptable behavior

- Insults, harassment, or sexual attention that was not asked for.
- Publishing someone’s private information.
- Using the issue tracker for spam or for traffic that has nothing to do with the project.

## Where it applies

GitHub issues, pull requests, and any other space that is represented as this project.

## Reporting

Open a GitHub issue, or use private vulnerability reporting if the report itself would reveal personal data. Maintainer of this repository: macodev00.

Someone who keeps breaking these rules can be blocked from the repository.
